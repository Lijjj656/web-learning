# JavaScript Demo 4：Fetch API 用户查询

## 运行方式

用 Visual Studio 2022 打开 `index.html`，再用浏览器打开。`app.js` 需要联网访问公开测试 API，因此查询时请保持网络连接。

## 操作步骤

1. 输入 `1`，点击“查询”，观察用户资料。
2. 输入 `10`，再次查询。
3. 输入 `99`，观察错误提示。
4. 打开浏览器开发者工具的 Network 面板，再查询一次，观察请求地址和响应数据。
5. 打开 `app.js`，按代码顺序阅读 `try`、`await` 和 `catch`。

## 修改任务

1. 把页面说明改成自己的文字。
2. 增加显示用户网站字段：`user.website`。
3. 查询成功后，把“查询成功”改成显示用户姓名。
4. 在 `try` 中增加一条 `console.log(user)`，在控制台查看完整 JSON。
5. 让编号不在 1 到 10 时，在发请求前直接显示提示。

## 完成标准

- 能说出 `fetch` 的作用。
- 能解释为什么请求结果要使用 `await response.json()`。
- 能解释 `try...catch` 如何处理网络或 API 错误。
- 能在 Network 面板中找到请求和响应。
