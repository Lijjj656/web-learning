# HTML Demo 1：个人学习主页

## 你要学会什么

本 Demo 练习 HTML 的页面骨架、语义化结构、图片、链接、列表、表格和表单。阅读源码时要能回答“这块内容为什么使用这个标签”。

## 运行方式（Visual Studio 2022）

1. 选择“文件 → 打开 → 文件”。
2. 打开当前目录的 `index.html`。
3. 修改后按 `Ctrl + S`。
4. 在文件资源管理器中双击 `index.html`，用浏览器查看。

## 推荐学习顺序

1. 先在浏览器查看页面，写下页面有哪些区域。
2. 回到源码，找到对应的 `header`、`main`、`section`、`article`、`footer`。
3. 修改一处文字并刷新浏览器，确认“源码 → 页面”的关系。
4. 完成练习，再阅读上级目录的 `HTML学习资料.md`。

## 练习任务

1. 把标题和自我介绍换成自己的真实内容。
2. 在“关于我”中增加一个“我的技能”小节。
3. 在表格中增加一行“嵌入式技术”。
4. 给表单增加手机号输入框，并使用 `type="tel"`。
5. 把 GitHub 占位链接换成自己的仓库地址；没有仓库时可以保留占位文字。

## 完成标准

- 导航可以跳到三个页面区域。
- 图片有准确的 `alt` 描述。
- 每个输入控件都有对应的 `label`。
- 表格表头使用 `th`，数据使用 `td`。
- 能解释：HTML 负责结构和内容，CSS 负责样式，JavaScript 负责交互。

表单现在不会保存数据，因为还没有 JavaScript 和后端；这是有意保留的边界。
